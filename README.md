## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/tanishkkashyap7/clixio-ai.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd clixio-ai
```

### 3️⃣ Install Dependencies

#### Frontend

```bash
npm install
```

#### Backend

```bash
cd clixio-backend
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file inside `clixio-backend/`

```env
GROQ_API_KEY=your_groq_api_key
PORT=3000
```

---

## ▶️ Run the Project

### Start Backend

```bash
cd clixio-backend
node server.js
```

### Open Frontend

Run frontend files using Live Server or open `website.html`
